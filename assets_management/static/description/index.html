Gestione Cespiti

Ammortamento e operazioni su beni/cespiti

This modules allows account management of companies' assets.

Italian assets management is very complex. This module manages all italian situations.

Please, read the "test/Test Workflow.xlsx" file with 4 asset examples.

Questo modulo permette di creare e gestire cespiti dalla sezione contabilità di Odoo.

Il modulo è progettato per gestire tutte le complesse situazioni italiane.

Si consiglia di guardare il file "test/Test Workflow.xlsx" usato come modello di sviluppo e test.

Usage | Utilizzo

You can create and manage assets from accounting section of Odoo.

To configure:

Assets » Assets Configuration » depreciation types

Assets » Assets Configuration » modes

Assets » Assets Configuration » assets categories

Assets can be created via invoices and journal entries or by menu:

Assets » Assets

Depreciations can be generated by using the related wizard found in

Assets » Assets Management » Generate Depreciations

Assets » Assets » triggering the same wizard from a single asset form view

La gestione beni ammmoritzzabili (cespiti) é una sezione della contabilità di Odoo.

Pr la configurazione dei cespiti:

Cespiti » Configurazione Cespiti » Tipi

Cespiti » Configurazione Cespiti » Modalità di ammortamento

Cespiti » Configurazione Cespiti » Categorie dei beni

I beni (cespiti) possono essere creati da fatture o registrazioni contabili o del menù:

Cespiti » Gestione Cespiti

Gli ammortamenti possono essere generati utilizzando l'apposito wizard in

Cespiti » Gestione Cespiti » Genera Ammortamenti

Cespiti » Gestione Cespiti » Eseguire lo stesso wizard dalla scheda del cespite
