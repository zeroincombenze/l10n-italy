Send E-Invoice to customer through SdI

Invio e-fatture a clienti tramite SdI

This module can send Italian e-invoices to Customer through Sdi

Questo modulo permette di inviare le fatture tramite uno canale Sdi

In questa versione è implementato uno specifico canale JSON verso hub di terzo incaricato e il canale PEC.
